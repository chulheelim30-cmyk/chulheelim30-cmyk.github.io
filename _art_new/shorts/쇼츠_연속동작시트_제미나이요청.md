# 풍년이의 모험 쇼츠: 제미나이 '연속 동작 시트' 요청 문장

지금 쇼츠는 그림 한 장을 늘였다 줄였다, 살짝 기울이는 방식으로 움직여요. 아래 시트를 받으면 눈 깜빡임, 꼬리 살랑, 날갯짓처럼 그림 자체가 바뀌는 움직임이 들어가서 GIF처럼 자연스러워져요.

**공통 방법**
1. 해당 캐릭터 그림 1장을 같이 올려요(풍년이는 `c_wave`, 까마귀는 `b_crow`, 왕년이는 `w_sit`, 꽥장군은 `b_goose`. 없으면 게임 화면 캡처도 괜찮아요).
2. 아래 상자 속 문장을 **공통 머리말 + 시트 문장** 순서로 붙여 넣어요.
3. 받은 그림을 그대로 보내 주시면 배경 지우기, 4배 선명화, 칸 나누기는 제가 해요.

**우선순위**: ★★★ = 1화를 바로 좋아지게 함, ★★ = 2화용, ★ = 있으면 더 좋음

---

## 공통 머리말 (모든 시트 앞에 붙이기)

```
첨부한 캐릭터와 똑같은 그림체(두꺼운 짙은 갈색 외곽선, 부드러운 셀 채색, 한국 웹툰풍)·색·얼굴·크기로 그려줘.
- 가로 한 줄 스프라이트 시트, 칸 크기는 모두 같은 정사각형, 순수한 흰 배경(#FFFFFF)
- 그림자·바닥선·반짝이·글자·칸 테두리 없음
- 모든 칸에서 캐릭터 크기가 같고, 발(또는 엉덩이)이 같은 높이에 닿아 있고, 몸 중심이 칸 가운데
- 칸과 칸 사이 움직임은 아주 조금씩만 달라지게(애니메이션 중간 그림처럼)
```

> 풍년이 시트에는 이 한 줄을 더 넣어요: `고양이는 코랫(은회색 단모, 털끝이 은빛, 흰 털 없음, 하트 모양 얼굴, 크고 동그란 초록 눈, 통통한 몸, 가는 꼬리)`

## 1화용

### ① 풍년이 앉아서 숨쉬기·눈 깜빡·꼬리 살랑 (6칸) ★★★
1화 거의 모든 장면에 써요(츄르 건네기 전, 친구가 된 뒤, 끝 화면).
```
오른쪽을 살짝 보고 앉아 있는 풍년이, 6칸(캔버스 가로 3072 x 세로 512, 칸 512x512).
1. 눈 뜨고 미소, 꼬리 끝이 오른쪽 아래
2. 1과 같고 꼬리 끝이 조금 위로 말림, 가슴이 살짝 부풂(숨 들이쉼)
3. 눈을 반쯤 감음, 꼬리 끝 가장 위
4. 눈 꼭 감음(깜빡), 귀 하나가 살짝 옆으로 쫑긋
5. 다시 눈 반쯤 뜸, 꼬리 끝 내려오는 중
6. 1번과 거의 같음(처음으로 이어지게)
```

### ② 풍년이 잠자며 숨쉬기 (4칸) ★★★
첫 장면(꿈꾸는 풍년이)용.
```
배를 보이고 벌러덩 누워 자는 풍년이(첨부 c_sleep 자세), 4칸(캔버스 2048 x 512, 칸 512x512).
1. 배가 가장 낮음, 입 살짝 벌림
2. 배가 반쯤 부풂, 앞발 끝이 살짝 오므려짐
3. 배가 가장 높음, 귀 하나가 살짝 움찔
4. 2번과 같음(1번으로 이어지게)
행복한 표정, 아프거나 다친 느낌 없이
```

### ③ 까마귀 날갯짓 (6칸) ★★★
방울 뺏고 날아가는 장면이 지금은 2장 번갈아라서 깜빡거려 보여요.
```
오른쪽을 향해 나는 까마귀(첨부 그림), 한 바퀴 날갯짓 6칸(캔버스 3072 x 512, 칸 512x512).
1. 날개 가장 위로 쭉
2. 날개가 어깨 높이로 내려오는 중
3. 날개 수평으로 활짝
4. 날개 가장 아래(몸 아래쪽까지 감쌈)
5. 날개가 접히며 올라가는 중
6. 날개 반쯤 올라옴(1번으로 이어지게)
부리는 다물고, 발은 몸 아래로 모음
```

### ④ 풍년이 츄르 건네기 (4칸) ★★
```
앉은 풍년이가 앞발에 츄르(분홍 봉지 간식)를 들고 오른쪽 친구에게 내미는 4칸(캔버스 2048 x 512).
1. 츄르를 가슴 앞에 꼭 쥐고 망설이는 얼굴
2. 고개를 끄덕이며 미소, 앞발이 앞으로 나가기 시작
3. 앞발을 오른쪽으로 쭉 내밀어 츄르를 건넴, 눈웃음
4. 빈 앞발을 살짝 흔듦, 활짝 웃음
```

### ⑤ 까마귀 시무룩 → 츄르 냠 → 하트 (5칸) ★★
```
왼쪽을 보고 땅에 앉은 까마귀(첨부 그림) 5칸(캔버스 2560 x 512).
1. 고개 숙이고 시무룩, 날개 축 처짐
2. 고개를 들고 깜짝(눈 동그랗게), 부리에 츄르 봉지 물기 시작
3. 츄르를 물고 냠냠, 볼이 살짝 빨개짐
4. 눈을 감고 행복, 가슴 털이 부풂
5. 날개를 살짝 펴고 폴짝, 머리 위에 작은 하트 1개
```

### ⑥ 상자 속 왕년이 빼꼼 (4칸) ★★ (1화 끝 + 2화 처음)
첨부: `w_box`
```
종이 상자 속 흰 바탕에 회색 얼룩 고양이(왕년이, 첨부 그림) 4칸(캔버스 2048 x 512). 상자는 모든 칸에서 같은 자리·같은 크기.
1. 상자 뚜껑만 보이고 귀 끝 두 개만 빼꼼
2. 눈까지 올라옴, 두리번(눈이 왼쪽)
3. 얼굴 전체가 나옴, 눈이 오른쪽, 귀 쫑긋
4. 앞발 두 개를 상자 가장자리에 걸치고 수줍은 미소
```

## 2화용 (시장 골목 꽥장군)

### ⑦ 왕년이 달리기 (6칸) ★★
첨부: `w_run0` 또는 `w_run1`
```
오른쪽을 향해 달리는 왕년이(흰 털, 머리·꼬리에 회색 얼룩, 복슬복슬 긴 털, 초록 눈) 6칸(캔버스 3072 x 512).
1. 앞다리 앞으로·뒷다리 뒤로 쭉(공중)
2. 앞다리 땅에 닿기 시작
3. 네 다리가 배 아래로 모임(몸 둥글게)
4. 뒷다리 땅을 박참
5. 앞다리 앞으로 뻗는 중
6. 1번 직전 자세
복슬한 꼬리는 칸마다 조금씩 출렁이게, 겁먹었지만 열심히 따라오는 얼굴
```

### ⑧ 꽥장군 뒤뚱 걷기·돌진 (6칸) ★★
첨부: `b_goose`
```
투구를 쓴 하얀 거위 꽥장군(첨부 그림)이 왼쪽을 향해 뒤뚱뒤뚱 걷는 6칸(캔버스 3072 x 512).
1. 왼발 앞, 몸이 왼쪽으로 기울
2. 두 발 모임, 몸 똑바로, 날개 살짝 들림
3. 오른발 앞, 몸이 오른쪽으로 기울
4. 두 발 모임, 목을 앞으로 쭉 빼기 시작
5. 목을 쭉 빼고 부리를 벌려 "꽥!", 날개 활짝
6. 4번과 같음(1번으로 이어지게)
화난 얼굴이지만 귀엽게, 투구 깃털은 칸마다 살짝 흔들림
```

### ⑨ 꽥장군 머리 콩 → 경례 (4칸) ★★
```
같은 꽥장군, 정면에서 살짝 왼쪽을 본 모습 4칸(캔버스 2048 x 512).
1. 머리에 작은 혹, 눈이 빙글빙글(어지러움), 투구가 비뚤어짐
2. 정신 차리고 투구를 바로 씀, 머쓱한 얼굴
3. 가슴을 펴고 오른쪽 날개를 이마에 붙여 경례, 씩씩한 얼굴
4. 경례한 채로 한쪽 눈 윙크, 부리 끝에 미소
```

### ⑩ 풍년이 생선 냄새 킁킁 (4칸) ★
```
오른쪽을 보고 선 풍년이 4칸(캔버스 2048 x 512).
1. 걷다가 멈춤, 귀 쫑긋
2. 코를 위로 들고 킁킁, 눈 감음
3. 입가에 침 한 방울, 행복한 눈(반달 눈)
4. 몸을 앞으로 쭉 내밀며 꼬리 꼿꼿이 세움
```
