# 풍년이의 모험 쇼츠 3~5화: Bing·Gemini 그림 요청

지금 있는 게임 그림으로도 3~5화를 먼저 만들어 둘게요. 아래 그림을 받으면 해당 장면을 바로 교체해요.
**Bing**(Image Creator)은 장면 그림(세로 9:16)에, **Gemini**는 캐릭터 그림을 첨부해서 같은 얼굴로 그려야 하는 동작 시트에 쓰는 걸 추천해요.

## 공통 말머리 (모든 장면 그림 앞에 붙이기)
```
세로 9:16 한 장, 한국 웹툰 동화풍, 두꺼운 짙은 갈색 외곽선, 부드러운 셀 채색, 따뜻한 빛.
주인공: 은회색 단모 코랫 고양이 풍년이(흰 털 없음, 하트 모양 얼굴, 크고 동그란 초록 눈, 통통한 몸, 가는 꼬리).
동생: 흰 바탕에 머리·꼬리만 회색 얼룩인 복슬복슬 긴 털 고양이 왕년이(초록 눈, 겁 많은 표정). **왕년이가 풍년이보다 한 덩치 더 큼**(동생이지만 몸집은 형보다 큼).
글자·말풍선·워터마크 없음. 화면 위쪽 1/4은 하늘이나 단순한 배경으로 비워 두기(자막 자리).
```

## 3화 · 지붕 위 바람 (빙글이 로봇)
**A. 꼬리 잡고 같이 점프** ★★★
```
기와지붕 위, 바람에 빨래가 펄럭이는 맑은 낮. 지붕과 지붕 사이 좁은 틈을 풍년이가 힘차게 뛰어넘고, 왕년이가 풍년이 꼬리를 앞발로 꼭 잡고 눈을 질끈 감은 채 같이 날아오르는 순간. 아래에는 장독대와 빨랫줄.
```
**B. 빙글이 로봇과 친구** ★★
```
머리에 프로펠러가 달린 동그란 흰색·하늘색 꼬마 로봇(얼굴 화면에 웃는 눈)이 풍년이와 왕년이 앞에 떠서 화면 속 화살표로 지름길을 알려 주는 장면. 기와지붕 위 노을 무렵.
```

## 4화 · 반딧불 산책길 (부엉 할매)
**C. 반딧불 별자리** ★★★
```
밤 호수공원 산책길. 수많은 반딧불이 하늘로 올라가 고양이 발바닥 모양 별자리를 만들고, 풍년이와 왕년이가 나란히 앉아 올려다보는 뒷모습. 가로등 불빛, 잔잔한 호수.
```
**D. 배부른 풍년이 벌러덩 + 코 콕** ★★
```
밤 풀밭에서 배를 보이고 벌러덩 누워 행복하게 자는 풍년이, 옆에서 왕년이가 코로 풍년이 볼을 콕 누르는 장면. 주위에 반딧불 몇 개.
```
**E. 부엉 할매** ★
```
보라색 숄을 두르고 동그란 안경을 쓴 다정한 부엉이 할머니가 나뭇가지에 앉아 미안한 듯 웃으며 날개로 머리를 긁는 장면. 아래에서 왕년이가 풍년이 뒤에 숨어 빼꼼.
```

## 5화 · 강 건너 절반 (너굴 대장)
**F. 다리 위에서 가슴 펴는 왕년이** ★★★
```
노을 진 강 위 나무다리. 왕년이가 처음으로 가슴을 활짝 펴고 앞장서 걷고, 풍년이가 뒤에서 흐뭇하게 웃는 장면. 강물에 노을 반짝임, 다리 가로등.
```
**G. 쓰레기통에 머리 낀 너굴 대장을 꺼내 주기** ★★
```
초록 쓰레기통에 머리가 낀 너구리(손에 츄르 봉지)를 풍년이와 왕년이가 양쪽에서 영차 당겨 꺼내 주는 장면. 노을 다리 위, 코믹하고 다정한 분위기.
```
